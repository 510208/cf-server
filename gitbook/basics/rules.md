# 📜 服內規則

{% hint style="info" %}
此玩家規則為[官網頁面](https://whiter.lnstw.xyz/rule)之備份，倘若官網已恢復，請各位玩家以官網公告為主，否則請以此頁規則公布為準！
{% endhint %}

為了各位玩家們的遊戲著想，敬請所有玩家皆需要照規則行事，否則伺服器有權執行相應處置。本規則最終解釋權於雲羽生存服管理團隊（係指由管理員、正副服主、工程師及其他直稱用戶組成，權限超越玩家之團隊）

{% hint style="warning" %}
如有未被以下規範舉例，但屬此規範範圍之情況，本服管理人員有最終解釋權。\
列出之要件為確定被判刑要件，但不代表其他項目不受法條規範
{% endhint %}

{% hint style="warning" %}
如有未特別指名罰則，皆請套用”違者處以**最低口頭警告、最高停權**之處分”
{% endhint %}

***

## 零、本規則適用範圍

本規則適用於雲羽生存服轄下之Minecraft伺服器，包括第一分流、主伺服器、測試分流與其他未來建立之分流。

在非雲羽生存服轄下之範圍、經合併但尚未公布適用此規範之範圍，不由此規範管理。若該範圍有其他優先順序更高之規範，則以該規範為主、此規範為輔。

倘若此規範未提及之範圍，由其他規範、中華民國相關法律等規範加以補充之，且必要時得以由管理團隊修改或補充。

## 一、禁止使用外掛

無論何種外掛，Aristois Client、WURST、Wolfan、Huzuni等，<mark style="background-color:red;">嚴禁使用此類破壞遊戲平衡外掛</mark>，如遭查獲，無論任何使用方式，一切**永BAN**

{% hint style="info" %}
外掛是指任何未經官方授權、修改或添加遊戲內容的程式或工具，包括但不限於以下類別：

* **客戶端外掛**：修改遊戲客戶端程式碼，以獲得額外的功能或優勢
* **伺服器端外掛**：修改伺服器端程式碼，以改變遊戲規則或設定
* **腳本**：使用指令或程式碼自動執行遊戲操作
* **整合包**：包含多種外掛或模組的整合套件
{% endhint %}

## 二、請不要冒犯他人

包括<mark style="background-color:red;">威脅、淫穢、誹謗、仇恨、騷擾、侮辱、刷屏、欺騙 …等相關行為</mark>，違者本服將處以**最低口頭警告、最高停權**之處分。

## 三、禁止惡意破壞他人建築

在不屬於自己的建築中，執行以下相關操作者皆符合罪刑構成要件：

* 挖掘
* 放置
* 重構
* 移動
* 其他在對方未同意狀況下執行之行為

相關行為皆於本條目規定範圍中。違者處以**最低口頭警告、最高停權**之處分

## 四、禁止於未經同意下偷竊他人物資

**無論對方是否有設定領地**，在不屬於自己擁有之領地範圍執行以下操作者皆為此條目管理之範圍其一：

* 拿取
* 放入
* 惡意鎖牌、鎖定
* 惡意鎖上物件
* 移除建築內容
* 其他行為由管理群處理

相關行為皆於本條目規定範圍中。違者處以**最低口頭警告、最高停權**之處分

{% hint style="info" %}
即使玩家未設定領地，偷取物品一概依此法處理。若該玩家未表明領地所有權則視情況判罰
{% endhint %}

## 五、禁止惡意傷害他人

除了在PvP允許區域並且對方同意狀況以外，執行以下操作者皆受此條管轄：

* 打擊
* 推動
* 惡意使玩家受到傷害
* 擊退墜落
* 釣竿

相關行為皆於本條目規定範圍中。

## 六、請勿使用漏洞

利用漏洞達成以下項目者，皆受此條管轄：

* 非法取得方塊
* 非法破壞方塊
* 其他非法行為

但執行以下操作者除外：

* 複製方塊
* 複製重力方塊
* 已批露且允許之行為（由管理群限制）

## 七、影響他人遊玩權益相關行為

### 7-1. 紅石與機關相關

本服禁止以下相關條件之紅石機關，若有特殊需求，可向管理員知會、並經過同意後方可執行：

{% hint style="info" %}
不合規機關包括但不限於以下項目：

* 造成伺服器效能瓶頸之機關，例如：卡服裝置等…
* 違反上列規則之機關
* 其他經管理員討論後之裝置
{% endhint %}

在本服中建造上列之不合規機關且未經申請，該機關將會被直接清空且不返還任何物件。有鑑於玩家無法得知伺服器效能狀況與影響、以及紅石機關之可變化性，故對於該機關是否合理，本服有最終解釋權

### 7-2. 公共聊天頻道之正確使用行為

在聊天頻道中請勿進行任何**宣傳、廣告、介紹、引導**或其他相關之交談討論。但以下聊天方式除外：

* 詢問是否可以購買，回答同意與否
* 忘記使用`/msg`指令，但一小時內最多兩次

如需討論此類訊息，請使用`/msg`指令私訊，或在交易頻道中使用

### 7-3 惡意造成伺服器卡頓

有鑑於Minecraft本身的限制，即便伺服器主機處理器有著複數核心，但通常只能使用到最多一個核心的效能，而隨者玩家的發展，逐漸有一些對伺服器可能產生卡頓之機械裝置、紅石機關等，可能影響到玩家的遊戲體驗，故訂立此子規範。

{% hint style="info" %}
如下為本服定義之伺服器卡頓行為，包括但不限於：

* 單一實體出生系統效率超過同時50個實體（不限制同一種實體）
* 放置大量實體，例如 TNT、TNT 引信、礦車、漏斗等
* 快速放置或破壞大量方塊
* 使用大量指令或紅石系統
* 利用漏洞或外掛程式
* 單一實體出生系統效率未達50個實體，但仍然影響伺服器效能
* 違反紅石相關規範中規定的機關
{% endhint %}

只要建造本類之機關，皆為違反規定，一律<mark style="background-color:red;">先行知會並給予3\~7天改善期間（無法上線依然計算）後仍未改善則拆除</mark>。倘若您對自己的機關有疑慮，歡迎向我們詢問

{% hint style="info" %}
以下部分請管理員詳細閱讀：

貼上藍圖僅限在貼上時上線玩家小於五人、或線上玩家皆同意此一行為時才可貼上

因Litematica模組貼上藍圖時會發送極大量封包，可能堵塞伺服器線程
{% endhint %}

### 7-5. 堆疊實體

倘若在伺服器中有<mark style="background-color:red;">符合以下情況之堆疊實體</mark>，我們會進行處理並警告：

* 超過3組掉落物在同一區塊內
* 超過50個實體在單一機關或同一區塊內
* 手動建立實體
* 非法取得實體建立

以上項目皆會進行控制，數值僅供參考，**倘若影響伺服器效能，即使未達標也可能進行處理**；倘若已達標但伺服器依然順暢，則會視情況決定是否處理

## 八、管理員規章

本規章中涉及到之管理員包括：

* 伺服器之<mark style="color:red;background-color:red;">**正副服主**</mark>
* <mark style="color:red;background-color:red;">**系統工程師**</mark>或有相同、相等權限之用戶
* 經服主或擁有相應權力的伺服器工作人員所任命，在伺服器中擁有<mark style="color:red;background-color:red;">**超過玩家可擁有之權力及權利**</mark>（如修改權限與身分組設定、後台檢視權限、op、創造模式、非正常遊戲模式等）者
* 經服主或擁有相應權力的伺服器工作人員所任命，在伺服器中<mark style="color:red;background-color:red;">**有權參與或直接、間接決斷伺服器相關事務**</mark>（無論重大與否）；或有權<mark style="color:red;background-color:red;">**公布規定且擁有正式效力**</mark>者
* 經服主或擁有相應權力的伺服器工作人員所任命，在伺服器中有權<mark style="color:red;background-color:red;">**管理、糾正，或對玩家執行其他相等動作**</mark>者
* 經服主或擁有相應權力的伺服器工作人員所任命，在<mark style="color:red;background-color:red;">**Discord或其他社交軟體群組中擁有超過玩家可擁有之權力及權利（如修改權限與身分組設定、檢視管理員專屬頻道、檢視副控室等）**</mark>者
* 無論透過何種方式，取得相關管理權限者

下文中提到的 「超玩家權限」 ，係指不等同或超過一般玩家所能擁有之權限

{% hint style="danger" %}
建築師、雲翎使者也有**部分適用於此規章**，但並非全部。若有此類廣義管理員須遵守之規範，會於該項規範中加上相關提示
{% endhint %}

### 8-1. 物品的增、刪、改、移

管理員不得給予、移除、修改或移動玩家或其他管理員所擁有之物品、方塊、實體或其他相關項目。倘若一遭發現執行此類操作，經確認並正式審理後，伺服器有權降級、移除權限或執行進階處分

### 8-2. 禁止干涉玩家或其他管理員之遊戲進程、進度

管理員不得以任何方式干涉玩家的正常遊戲進程，如：

* 不得無故<mark style="background-color:blue;">傳送玩家</mark>（TP）至特定地點
* 不得使用管理員權限<mark style="background-color:blue;">影響玩家的生存環境</mark>（如隨意生成或摧毀方塊、召喚怪物或實體）
* 不得使用管理員指令<mark style="background-color:blue;">強制改變玩家的狀態</mark>（如設定無敵、清除效果）

若玩家因伺服器錯誤導致遊戲受影響，應由管理團隊評估後統一處理

### **8-3. 禁止濫用權限或擅自變更權限（遊戲內與後台皆適用）**

管理員不得擅自變更自己的權限，包含<mark style="background-color:red;">提升自己的身分組、賦予自己額外權限</mark>等，亦不可對其他玩家或管理員執行以上操作，在未經服主或其他高階管理員之同意下（若有經同意且在同意範圍內則除外）

若有必要調整權限，應<mark style="background-color:blue;">向服主或核心管理團隊</mark>申請；若違反此規章，經管理團隊評估後統一處理

另外，在未經許可下濫用權限於系統後台執行以下操作者，必須在管理團隊評估後統一處理

除非有明確原因或緊急狀況，管理員不得使用管理指令影響玩家（如 `kill`、`ban`、`mute`、`give`）

禁止利用後台權限查看玩家個資（如 IP 位址、登入記錄）或進行與管理無關的操作，且禁止擅自變更伺服器設定。若需調整，應事先報備並取得授權

### 8-4. 禁止在權限外濫用處罰權限

倘若因個人恩怨、團體仇恨、公會問題等與玩家引發衝突，進而<mark style="background-color:red;">透過自身之超玩家權限傷害、修改或違反此規則，或經管理團隊審核後確定不合理或不合當下需求之操作</mark>。無論對玩家或系統、伺服器世界等端點造成之傷害皆屬於此規定規範之內容

* 不得因個人情緒或私人恩怨對玩家實施處罰（如封禁、禁言）
* 若需對玩家進行處罰，應根據伺服器規則，並向管理團隊報告
* 若玩家對處罰有異議，請參照附錄中給予之處理方式，由管理團隊共同審理

{% hint style="info" %}
濫用權限的核心定義為：**利用管理員權限做出超出正常管理範圍、不公正或不道德的行為，影響遊戲公平性、玩家體驗，或損害伺服器的正常運作**。

如發現管理員有以上行為，應立即回報給 **服主或核心管理員**，並交由管理團隊討論與處理。
{% endhint %}

### **8-5. 禁止洩露伺服器內部資訊**

管理員不得將伺服器內部機密資訊，如<mark style="background-color:red;">管理後台、內部討論、未公開更新計畫等對外公開</mark>；並禁止將管理員專屬頻道內的訊息、內部決策過程洩漏給非管理員玩家

違反此規定者將視情節輕重，予以降級或移除權限

### 8-6. 管理員行為規範

管理員應保持良好態度，避免對玩家<mark style="background-color:red;">使用侮辱性語言或惡意嘲諷</mark>。

禁止利用管理身份對玩家進行任何形式的騷擾、欺壓或不當行為。若有玩家提出管理員行為不當的申訴，應<mark style="background-color:blue;">由其他管理員或服主</mark>進行調查

## 九、修改此規章之相應規則

本伺服器有權更正此規定之內容，並在不影響當前玩家遊玩之前提下，更改此規定之內容。如果玩家有任何異議或建議，歡迎與我們討論！

## 附錄

### 一、建築被破壞、偷竊之補償標準

請向管理員申請補償，並會依照官方之處理程序規章進行處理

### 二、對被封禁玩家之領地影響與移除標準

如果被封禁者的領地影響到未被封禁者之建築或使用，請向管理員申請處理，並提供以下資料：

* 領地名
* 領地擁有者MC帳號
* 領地位置
* 申請緣由

請確定申請符合以下項目：

1. 該領地擁有者為被封禁者
2. 申請移除者需未被封禁
3. 被封禁者不得為暫時封禁或有限時封禁
4. 該領地其他具權限之成員皆同意移除

### 三、暫時封禁及有限制封禁

| 暫時封禁                  | 監禁                      | 有限制封禁             |
| --------------------- | ----------------------- | ----------------- |
| 較重                    | 中等                      | 較輕                |
| 封禁期間不得執行任何操作，並不得加入伺服器 | 可加入伺服器，但須被監禁在監獄中，而非自己領地 | 可加入伺服器，但無法離開自己的領地 |
| 不得要求賠償任何損失            | 不得要求賠償任何損失              | 不得要求賠償任何損失        |

### 四、如何申請

在本規定中所有”向管理員申請”之事項皆請使用以下方法之一處理：

* 在 ঌ〃📃｜⋛客服單⋚ 頻道中申請
* 私訊管理員（如果客服單超過一周未受理）

若不使用以上方法，則團隊有權不受理並禁止相關事件再次受理
