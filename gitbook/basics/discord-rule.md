# 📜 群組規則

為了各位玩家們的聊天安全著想，請各位遵守此群組規則。在服外之互動由此規則主管，且本服管理團隊（係指由管理員、正副服主、工程師及其他直稱用戶組成，權限超越玩家之團隊）擁有最終解釋權。



{% hint style="warning" %}
如有未被以下規範舉例，但屬此規範範圍之情況，本服管理人員有最終解釋權。\
列出之要件為確定被判刑要件，但不代表其他項目不受法條規範
{% endhint %}

{% hint style="warning" %}
如有未特別指名罰則，皆請套用”違者處以**最低口頭警告、最高停權**之處分”
{% endhint %}

***

本規則適用於雲羽生存服官方所建立之各類群組（包括但不限於<mark style="background-color:blue;">**Discord 伺服器、Facebook 粉絲專頁、社群平台群組**</mark>），以維護群組秩序及確保所有成員均能在和諧、安全之環境下交流。

倘若成員違反本規範，管理員得視情節輕重，執行<mark style="background-color:red;">警告、禁言、移除成員</mark>等處分，並於必要時同步至 Minecraft 伺服器內執行相應懲處。

倘若此規範未提及之範圍，由<mark style="background-color:blue;">其他規範、該社群平台之官方規範與中華民國相關法律</mark>等規範加以補充之，且必要時得以由管理團隊修改或補充。

## **一、禁止發表違法、不當或惡意內容**

雲羽生存服群組係供玩家交流之場域，倘若發表涉及違法、暴力、歧視、色情或其他嚴重影響群組秩序之內容，將予以刪除，並對發言者進行適當懲處。

**事相關事例：**

* 發表涉及**非法交易、詐騙、盜版、毒品、成人內容**之言論或連結。
* 散布包含**仇恨言論、種族歧視、性別歧視、宗教攻擊**之內容。
* 發布過於血腥、暴力、令人不適之圖片或影片。

{% hint style="success" %}
成人內容得於已設定NSFW提示之頻道中發表，但請勿踰矩。
{% endhint %}

## **二、禁止人身攻擊、惡意騷擾**

群組內所有成員應以禮相待，不得對其他成員進行<mark style="background-color:red;">**惡意謾罵、侮辱、霸凌、挑釁**</mark>，亦不得長時間糾纏、蓄意擾亂其正常交流。

**相關事例：**

* 以辱罵性詞彙攻擊他人（如：「你根本不會玩」、「XX 是廢物」）。
* 反覆@特定玩家，意圖騷擾或影響其正常使用群組。
* 於討論中故意引戰，或使用**諷刺、揶揄、貶低**之語句挑起爭端。

## **三、禁止洗版與發送無意義訊息**

洗版行為係指影響其他玩家正常交流，包含<mark style="background-color:red;">**連續發送大量重複內容、無意義符號、過長的文字或圖片**</mark>，或於短時間內大量發言影響閱讀體驗。

**事例**：

* 連續發送多則相同或相似內容（如：「幫助我！幫助我！幫助我！」）。
* 發送過長的無意義文字，如「哈哈哈哈哈哈哈哈哈哈哈哈」或「wwwwwwwwww」。
* 在短時間內發送大量貼圖、圖片，影響他人閱讀。

## **四、禁止討論無關之爭議話題**

群組係供玩家交流遊戲相關資訊，非討論政治、宗教、社會爭議等敏感議題之場所。倘若討論過於激烈或引發糾紛，管理員得依情況介入並要求停止討論。

我們支持言論自由，在適當狀況下的相關話題、聊天中順帶提及等合理情況下，我們不會對成員的聊天內容加以限制。此條目僅在聊天內容過激、違反其他規範時會介入處理。否則言論應該是自由、受到保障的，沒有任何人可以禁止任何人移除任何言論，即使雙方立場相衝。

**事例**：

* 在群組內直接討論政治立場，並對他人言論進行攻擊。
* 針對特定宗教信仰發表挑釁言論，或試圖強迫他人接受特定觀點。
* 於群組內蓄意引戰，導致成員間出現爭執。

## **五、禁止惡意批評或散布不實資訊**

成員應基於事實發表意見，並以理性態度討論。倘若惡意攻擊伺服器或管理團隊，或散布不實資訊導致玩家誤解，將視情節處理。

倘若玩家對管理團隊之處置有任何認為不妥當之處，歡迎向我們舉報或通知！

**事例**：

* **惡意造謠**伺服器將關閉，導致玩家恐慌。
* 無憑據指控管理員濫用權限，試圖煽動其他玩家對立。
* 故意誇大或扭曲事件，以達成個人目的（如：「管理員只幫VIP 玩家，不管普通玩家」 ）。

## **六、禁止未經許可之廣告或外部宣傳**

禁止發送任何與雲羽生存服無關之廣告、邀請連結或其他伺服器推廣內容，除非事先獲得管理員許可。如為聊天中即時提及，管理團隊應視情況不予以刪除。

如希望可與本伺服器合作宣傳、交換連結、贊助等，歡迎私訊服主或於客服單中處理，我們歡迎各位的加入與正向合作！

**事例**：

* 發送其他Minecraft伺服器的邀請連結、宣傳文件等。
* 於公開頻道內提及其他玩家或私訊，邀請加入其他群組或平台。

## **七、尊重管理團隊，服從合理指令**

**管理團隊**負責維護群組秩序，成員應尊重管理團隊的決定，並<mark style="background-color:red;">服從合理指令</mark>。<mark style="color:yellow;background-color:yellow;">**倘若對處理方式有異議，可透過正式管道申訴**</mark>，而非於公開場合質疑或攻擊管理團隊。

**事例**：

* 在公開頻道內質疑管理員決策，並引發其他玩家不滿。
* 於管理員執法時挑釁，如：「有本事你就封我啊」。
* 因個人情緒因素惡意攻擊管理員，如：「這群管理根本沒用」。

## **八、禁止冒充管理員或假借管理名義行動**

除正式管理團隊成員外，任何人皆不得冒充管理員，亦不得假借管理之名義對玩家發佈錯誤資訊或進行管理行為。

**事例**：

* 以「我是內部人員」、「管理員朋友」等名義發表不實公告。
* 未經許可假裝為管理員，要求玩家提供個資或進行交易。
* 在群組內擅自發佈伺服器規則，且內容與官方不符。

<mark style="color:red;background-color:red;">**如因冒充管理員而造成法律責任，本服一概不負責、不負連帶責任**</mark>等。因此也希望各位玩家從身分組、語言可疑之處、回覆訊息等加以判斷，如有冒充管理員者，可向正式團隊檢舉

## 九、修改此規章之相應規則

本伺服器有權更正此規定之內容，並在不影響當前玩家遊玩之前提下，更改此規定之內容。如果玩家有任何異議或建議，歡迎與我們討論！
