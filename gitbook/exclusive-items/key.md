# 🔑 鑰匙

{% hint style="info" %}
本功能為在 1.21.4 更新後（2025/1/30，週四）更新的新功能
{% endhint %}

## 說明

拿出鑰匙，回家吧！

取出本伺服器獨家創造的鑰匙系統，一把鑰匙配一扇門，一扇門、一把鑰匙，就是證明你家的證據！不讓任何人未經許可闖入自己的家，讓你的家園受到最簡單的保護

## 合成

### 原料

* 鐵錠 \*1
* 控制桿 \*1

### 擺放方式

![](../.gitbook/assets/crafting-grid.png)

中間放置鐵錠、下方放置控制桿，即可合成鑰匙

## 使用說明

如需與門配對，只要左鍵單按門就可以配對。在配對完成後會跳出 `已放置掛鎖 如果要移除它 請破壞此方塊` 這則訊息通知你！

如果要移除這把鑰匙的配對，直接拆除那扇門即可喔
